# 阿里云资源购买指南

## 第一步：购买 ECS 云服务器

### 1. 登录阿里云控制台
访问 https://www.aliyun.com/ 并登录您的账号

### 2. 进入 ECS 控制台
- 点击顶部菜单「产品」→「弹性计算」→「云服务器 ECS」
- 或直接访问：https://ecs.console.aliyun.com/

### 3. 创建实例
点击「创建实例」，按以下配置选择：

| 配置项 | 推荐选择 | 说明 |
|-------|---------|------|
| **付费模式** | 按量付费（测试）/ 包年包月（生产） | 包年包月更划算 |
| **地域** | 华东1（杭州）或 华北2（北京） | 选择离用户近的 |
| **实例规格** | ecs.t6-c1m2.large（2核4G） | 入门配置 |
| **镜像** | Ubuntu 22.04 64位 | 推荐 |
| **系统盘** | 高效云盘 40GB | 够用 |
| **带宽** | 按使用流量计费 5Mbps | 或固定带宽 |
| **安全组** | 新建安全组 | 下一步配置 |

### 4. 配置安全组
创建实例时会提示配置安全组，添加以下规则：

| 端口 | 协议 | 授权对象 | 说明 |
|-----|------|---------|------|
| 22 | TCP | 0.0.0.0/0 | SSH 登录 |
| 80 | TCP | 0.0.0.0/0 | HTTP |
| 443 | TCP | 0.0.0.0/0 | HTTPS |
| 3002 | TCP | 0.0.0.0/0 | API 端口 |

### 5. 设置密码
- 设置 root 密码（请记住！）
- 或使用 SSH 密钥对

### 6. 完成购买
确认订单并支付

### 7. 记录信息
购买成功后，记录以下信息：
- **公网 IP**: ________________
- **内网 IP**: ________________
- **root 密码**: ________________

## 第二步：购买 RDS PostgreSQL

### 1. 进入 RDS 控制台
- 点击顶部菜单「产品」→「数据库」→「云数据库 RDS」
- 或直接访问：https://rdsnext.console.aliyun.com/

### 2. 创建实例
点击「创建实例」，按以下配置选择：

| 配置项 | 推荐选择 | 说明 |
|-------|---------|------|
| **付费模式** | 按量付费（测试）/ 包年包月（生产） | |
| **地域** | 与 ECS 相同 | **重要！** |
| **数据库引擎** | PostgreSQL | |
| **版本** | 14.0 | 稳定版本 |
| **系列** | 基础版（测试）/ 高可用版（生产） | |
| **规格** | 1核2G（入门）/ 2核4G（推荐） | |
| **存储** | 20GB SSD | 可扩容 |

### 3. 创建数据库账号
实例创建完成后：
1. 进入实例详情
2. 左侧菜单选择「账号管理」
3. 创建账号：
   - 账号名：`boxadmin`（示例）
   - 密码：设置强密码
   - 账号类型：高权限账号

### 4. 创建数据库
1. 左侧菜单选择「数据库管理」
2. 创建数据库：
   - 数据库名：`germany_box_transport`
   - 字符集：UTF-8

### 5. 配置白名单
1. 左侧菜单选择「数据安全性」→「白名单配置」
2. 点击「修改」
3. 添加 ECS 的**内网 IP**

### 6. 记录连接信息
在「数据库连接」页面记录：
- **内网地址**: ________________（如：rm-xxxx.pg.rds.aliyuncs.com）
- **端口**: 5432
- **数据库名**: germany_box_transport
- **用户名**: boxadmin
- **密码**: ________________

## 第三步：连接服务器

### 使用终端连接（Mac/Linux）
```bash
ssh root@您的ECS公网IP
```

### 使用 PuTTY 连接（Windows）
1. 下载 PuTTY：https://www.putty.org/
2. Host Name 输入 ECS 公网 IP
3. Port 输入 22
4. 点击 Open
5. 输入用户名 root 和密码

---

## 第四步：上传代码

### 方式一：使用 SCP（推荐）

**Mac/Linux:**
```bash
# 在本地终端执行
scp -r /Users/fengzheng/德国Box系统 root@ECS公网IP:/var/www/germany-box-system
```

**Windows:**
使用 WinSCP 工具：
1. 下载 WinSCP：https://winscp.net/
2. 连接服务器
3. 拖拽上传文件夹

### 方式二：使用 Git

如果代码已推送到 GitHub：
```bash
# 在服务器上执行
cd /var/www
git clone https://github.com/您的用户名/仓库名.git germany-box-system
```

---

## 第五步：配置环境变量

```bash
# 复制配置文件
cp /var/www/germany-box-system/deploy/production.env /var/www/germany-box-system/server/.env

# 编辑配置
nano /var/www/germany-box-system/server/.env
```

修改以下内容：
```
DATABASE_URL=postgresql://boxadmin:您的密码@RDS内网地址:5432/germany_box_transport
JWT_SECRET=生成一个随机字符串
CORS_ORIGIN=http://您的ECS公网IP
```

生成随机字符串：
```bash
openssl rand -base64 32
```

---

## 第六步：运行部署脚本

```bash
cd /var/www/germany-box-system
chmod +x deploy/deploy.sh
./deploy/deploy.sh
```

---

## 完成！

部署成功后，访问：
- 后台管理：http://ECS公网IP/admin
- 客户端：http://ECS公网IP/customer

默认登录账号：
- 用户名：admin
- 密码：初始化数据库时通过 `SEED_ADMIN_PASSWORD` 环境变量设定，**不在仓库中记录**

## 常见问题

### Q: 连接服务器失败？
A: 检查安全组是否开放 22 端口

### Q: 数据库连接失败？
A: 检查 RDS 白名单是否添加了 ECS 内网 IP

### Q: 网站无法访问？
A: 检查安全组是否开放 80 端口
