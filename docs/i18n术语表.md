## 已知需要重点确认的几个词

| 中文 | 现用德语 | 备选 | 说明 |
|---|---|---|---|
| 承运商门户 | Frachtführer-Portal | Transportunternehmer-Portal / Spediteur-Portal | Frachtführer 是 HGB 法律用词，Spediteur 指货代（我们自己才是 Spediteur），此处对方是实际承运人 |
| 待接单 | Annahme ausstehend | Zu bestätigen / Offene Aufträge | 指订单已派给承运商、等对方点"接单" |
| 费用结算 | Abrechnung | Zahlungen / Gutschriften | 这里是我们付给承运商的应付账款 |
| 清关中 | Verzollung | Zollabfertigung | 两者都通用，看行业习惯 |
| 货损 | Schaden | Schadensvermerk | CMR 上的货损批注 |
| 税号 | Steuernummer | USt-IdNr. | 若实际要的是欧盟增值税识别号，应改 USt-IdNr. |
| 银行账号 | Bankkonto / Kontonummer | IBAN | 欧洲实务上基本只填 IBAN，可能该直接叫 IBAN |
