# 踩坑记录 004：状态枚举大小写不匹配导致筛选无结果

## 问题现象
订单列表页面点击"待审核"等筛选 Tab 时，始终显示"暂无订单数据"，但"全部"Tab 有数据。

## 根本原因
数据库中状态值是**大写**（`PENDING_REVIEW`、`CURTAIN_SIDE`），但前端筛选 Tab 的 key 用了**小写**（`pending_review`、`curtain_side`）。SQL 查询 `WHERE status = 'pending_review'` 匹配不到大写的数据。

## 错误代码
```javascript
// ❌ 错误
const TABS = [
  { key: 'curtain_side', label: '篷布车运输' },
  { key: 'pending_review', label: '待审核' },
]
```

## 正确代码
```javascript
// ✅ 正确：和数据库一致用大写
const TABS = [
  { key: 'CURTAIN_SIDE', label: '篷布车运输' },
  { key: 'PENDING_REVIEW', label: '待审核' },
]
```

## 防护规则
**前端所有状态枚举值、业务类型枚举值必须与数据库存储的值大小写完全一致（全大写）。**
