# 踩坑记录 005：PM2 restart 不加载新环境变量

## 问题现象
在 `.env` 文件中添加了新的环境变量（如 SMTP、OSS 配置），`pm2 restart all` 后，后端代码仍然读不到新变量，日志显示"SMTP 未配置"。

## 根本原因
PM2 cluster 模式下，`pm2 restart` 只重启 worker 进程，不会重新加载 `.env` 文件。环境变量在 PM2 master 进程启动时就已经固定了。

## 错误做法
```bash
# ❌ 这样不会加载新 .env
pm2 restart all
pm2 restart all --update-env  # 有时也不生效
```

## 正确做法
```bash
# ✅ 删除重建进程
pm2 delete all
cd /var/www/germany-box-system
pm2 start server/app.js --name germany-box-server -i 2
```

## 防护规则
**修改 .env 文件后，必须 `pm2 delete all` 再 `pm2 start`，不能只 `pm2 restart`。**
