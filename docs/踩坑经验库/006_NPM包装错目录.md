# 踩坑记录 006：npm install 装到了错误的目录

## 问题现象
后端启动报错 `Cannot find package 'ali-oss'`，但明明已经 `npm install ali-oss` 过了。

## 根本原因
项目是 monorepo 结构（根目录 + admin + customer-portal + carrier-portal + server），在**根目录**执行 `npm install ali-oss` 会装到根目录的 node_modules，但 server 有自己独立的 package.json 和 node_modules。

## 错误做法
```bash
# ❌ 在根目录安装
cd /var/www/germany-box-system
npm install ali-oss
```

## 正确做法
```bash
# ✅ 在 server 目录安装
cd /var/www/germany-box-system/server
npm install ali-oss
```

## 防护规则
**后端依赖必须在 `server/` 目录下安装，前端依赖在 `admin/` 目录下安装。不要在项目根目录安装。**
