## 二、表格结构（14 个字段）

### 苏总一方填（表单里的 9 题）

| 字段 | 类型 | 必填 | 填什么 |
|------|------|------|--------|
| 提交人 | 文本 | ✅ | 谁提的，方便后续对接确认 |
| 所属模块 | 单选 | ✅ | 14 个选项，见下方 |
| 意见类型 | 单选 | ✅ | 新功能需求 / 功能优化 / Bug反馈 / 界面体验 / 业务流程调整 / 其他 |
| 优先级 | 单选 | ✅ | 紧急 / 高 / 中 / 低 |
| 意见标题 | 文本 | ✅ | 一句话说清楚要什么 |
| 现状描述 | 文本 | ✅ | **现在是怎样的、哪里不方便** |
| 期望效果 | 文本 | ✅ | **希望改成怎样**（不用管技术怎么实现） |
| 相关页面 | 文本 | — | 哪个端、哪个菜单、哪个页面 |
| 附件 | 附件 | — | 截图直接拖进去 |

### 系统自动填

| 字段 | 类型 | 说明 |
|------|------|------|
| 提交时间 | 创建时间 | 提交那一刻自动记录，谁都不用填 |

### 我方开发填（表单里已隐藏，只在后台表格可见）

| 字段 | 类型 | 填什么 |
|------|------|--------|
| 处理状态 | 单选 | 待评估 / 已确认待开发 / 开发中 / 已上线 / 暂不实现 |
| 开发方回复 | 文本 | 评估结论、方案说明，或说明为什么暂不实现 |
| 预计上线时间 | 日期 | 排期后填 |
| 实际完成日期 | 日期 | 上线当天填 |

## 五、日常使用

1. 苏总提交后，记录自动进后台表格，「提交时间」自动带上
2. 我方在表格里逐条填「处理状态」和「开发方回复」
3. 想按优先级或模块看，用表格上方的「筛选」/「排序」/「分组」
4. 如果希望苏总也能看到处理进度：另建一个视图，把文档「分享」设为**可阅读**，单独发那个链接（**不要**给编辑权限）

---

## 六、想改表格时

- **加选项**（比如新增一个模块）：点字段名 → 编辑 → 添加选项。表单会自动跟着变
- **加字段**：表格里新增字段后，默认**不会**出现在表单里，要去表单视图左侧「可选题目」里点 `+` 加进来
- **关掉对外提交**：表单视图右上角「已开启分享」→ 关掉开关，链接立刻失效
