## 功能说明

合作方推单后凭自己的 `externalOrderNo` 随时查进展，补齐"推得进来、查不到结果"的缺口：

| 端点 | 返回 |
|------|------|
| `GET /api/open/v1/inquiries/{externalOrderNo}` | 询价状态 + 最新一版客户可见报价（金额/币种/有效期）+ 已转订单号 |
| `GET /api/open/v1/orders/{externalOrderNo}` | 订单状态（含中文 label）、派送子状态、跟踪号、柜号、计划日期 |

规则：
- **404 语义租户隔离**（架构规则 8）：查不到和"单号是别人的"一律 404 NOT_FOUND，不暴露存在性
- **成本永不外泄**（踩坑 026）：报价点名列查询，carrier_cost 不进响应；冒烟里有插成本再回查的回归断言
- 报价只取 `status NOT IN (DRAFT, CANCELLED)` 的最新版本；NUMERIC 金额出门前转数字（踩坑 002）
