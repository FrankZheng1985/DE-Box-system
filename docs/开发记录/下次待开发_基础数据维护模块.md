# 待开发：基础数据维护模块

> 优先级：P1 | 预估工作量：中等

## 需求背景
订单创建表单中的卸港、船司、国家等字段目前是手动输入或硬编码下拉，需要改为从基础数据库动态读取，支持后台维护。

## 需要维护的基础数据

| 数据类型 | 字段 | 使用场景 |
|---------|------|---------|
| 欧洲港口 | 港口名、国家、港口代码 | 集装箱订单的"卸港"字段 |
| 船司 | 船司名、英文名、代码 | 集装箱订单的"船司"字段 |
| 国家 | 国家名、代码、中/英/德名 | 所有地址选择 |
| 城市 | 城市名、国家、邮编前缀 | 地址自动补全 |
| 柜型 | 柜型代码、描述、尺寸 | 集装箱订单的"柜型"字段 |
| 车辆类型 | 类型名、描述 | 承运商车队管理 |
| 特殊要求 | 要求名、描述 | 订单特殊要求选择 |
| 币种 | 币种代码、名称、符号 | 所有金额字段 |

## 技术方案

### 数据库
```sql
CREATE TABLE basic_data_categories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  category_code VARCHAR(30) NOT NULL UNIQUE,  -- PORT/SHIPPING_LINE/COUNTRY/CITY/CONTAINER_TYPE...
  category_name VARCHAR(100) NOT NULL,
  description TEXT,
  is_active BOOLEAN DEFAULT true
);

CREATE TABLE basic_data_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  category_id UUID NOT NULL REFERENCES basic_data_categories(id),
  item_code VARCHAR(50) NOT NULL,
  item_name VARCHAR(200) NOT NULL,
  item_name_en VARCHAR(200),
  item_name_de VARCHAR(200),
  parent_id UUID REFERENCES basic_data_items(id),  -- 层级关系（如城市→国家）
  extra_data JSONB,                                 -- 扩展数据（如港口坐标、柜型尺寸）
  sort_order INTEGER DEFAULT 0,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(category_id, item_code)
);
```

### 后端 API
- GET /api/v1/basic-data/categories — 分类列表
- GET /api/v1/basic-data/:categoryCode — 某分类下的所有项
- POST /api/v1/basic-data/:categoryCode — 新增项
- PUT /api/v1/basic-data/items/:id — 编辑项
- DELETE /api/v1/basic-data/items/:id — 停用项
