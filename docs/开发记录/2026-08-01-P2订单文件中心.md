# P2 · 订单文件中心（需求 3）

**日期**：2026-08-01
**模块**：订单 / CMR / 客户门户 / 承运商门户

---

## 功能说明

以订单为维度管理文件，按状态引导上传：

| 类别 | 值 | 说明 |
|------|-----|------|
| 装车图 | `LOADING_PHOTO` | 要求车牌和货物清晰可见 |
| CMR 单据 | `CMR` | **仍存 `cmr_documents`**（签署状态/货损是它的专属价值），订单文件接口做统一视图聚合 |
| 签收凭证 | `POD_PROOF` | 命名刻意避开 `orders.pod`（卸港） |
| 其他 | `OTHER` | |

**状态引导**：运输中（FTL 看派送子状态）→ 建议补装车图 + CMR；已送达/运输完成/已完成 → 再加签收凭证；缺件黄色提醒。

**存储**：与 CMR 同一套约定——multer memoryStorage（20MB，PDF/JPG/PNG/WebP）→ OSS `orders/{订单号}_{柜号}/{时间戳}-{文件名}`，OSS 不可用回退本地 `/var/www/germany-box-system/uploads/orders/`。
