## 品牌色彩

| 颜色 | HEX | 用途 |
|------|-----|------|
| 深海军蓝 | `#1A365D` | 主色、文字、深色背景 |
| 中蓝色 | `#2B6CB0` | 强调色、链接 |
| 暖橙色 | `#F6AD55` | BOX 文字、装饰线、CTA |
| 白色 | `#FFFFFF` | CARGO 文字（深色背景时） |
| 灰色 | `#718096` | 次要文字、SERVICE GMBH |

## 设计规则

- BOX 始终为橙色 `#F6AD55`
- CARGO 在深色背景为白色，浅色背景为深蓝 `#1A365D`
- 中间分隔点 · 始终为半透明色
- SERVICE GMBH 使用大字距排版
- 最小使用尺寸：紧凑版不小于 150px 宽
